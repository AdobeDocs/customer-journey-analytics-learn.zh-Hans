# [!DNL Customer Journey Analytics]的Data Mirror

跨云数据仓库和[!DNL Customer Journey Analytics] (CJA)保持客户数据的一致性可能具有挑战性。 组织通常依赖手动流程来同步更新，这会增加数据工程团队的工作，并增加系统之间出现差异的风险。

Data Mirror通过自动将所支持的云数据仓库（如Snowflake、BigQuery和Databricks）中的更改反映到CJA中，从而简化了这一过程。 通过减少手动操作并保持系统一致，团队可以确保用于分析的数据保持最新。 本视频演示了Data Mirror的工作方式，并介绍在Adobe Experience Platform中配置该功能的步骤。

有关其他信息，请访问[文档](https://experienceleague.adobe.com/en/docs/analytics-platform/using/cja-data-mirror/relational){target="_blank"}。
